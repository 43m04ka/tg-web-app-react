# Отзывы покупателей

Локальная ветка `codex/customer-reviews`, основа `origin/master` (`a3dafcd`). Изменения лежат в отдельной папке `tg-web-app-reviews`; прежние рабочие папки не изменены. Push и деплой не выполнялись.

`/reviews` — реальные отзывы, рейтинг и количество, мобильные карточки и сетка на ПК. Раздел добавлен в меню, старые `/info/reviews` перенаправляются сюда. Вкладка «Мои покупки» показывает оплаченные и выполненные заказы, по которым можно оставить отзыв, либо отметку о ранее оставленном отзыве. Кнопки добавлены и в историю заказов.

`/reviews/write/:orderId` — отзыв по своему заказу после входа. `/reviews/write#token=…` — форма по персональной ссылке. Формы доступны без выбора витрины. Оценка 1–5, имя или ник, текст до 3000 символов, до четырёх JPG/PNG/WebP по 5 МБ, отдельные обязательные согласия на обработку и публикацию. Ссылки ведут на существующие документы проекта.

В карточке заказа Admin2 есть кнопки отправки и копирования ссылки. Отправка требует отдельного нажатия и подтверждения; после копирования ссылка также доступна в поле для ручного копирования. Автоматической отправки нет.

## Проверки

`CI=true npm test -- --watchAll=false --runInBand` — тесты проекта. Production-сборка для проверки: `BUILD_PATH=build-reviews-checked GENERATE_SOURCEMAP=false npm run build` (переменные задаются синтаксисом вашей оболочки).

`node scripts/reviews-preview.cjs <абсолютный путь к playwright-core> <папка результатов>` запускает изолированное превью production-сборки в установленном Chrome, подменяет все API-запросы и блокирует остальные внешние запросы. Имя папки сборки можно передать через `REVIEWS_BUILD_DIR`. Проверяются мобильная прокрутка, форма и оба согласия, публикация, аккаунт, копирование и подтверждённая отправка ссылки из админки. Создаются пять скриншотов и `browser-check.json`.

Скриншоты сделаны в настоящем браузере на вымышленных тестовых данных. Они не показывают отзывы реальных покупателей. Локальные сборки и node_modules не предназначены для коммита. Для ветки используется junction на существующие зависимости фронтенда; его нельзя удалять рекурсивными командами очистки.

Бэкенд подготовлен в соседней папке `tg-web-app-server-reviews`. Перед будущей публикацией потребуется его миграция `migrations/customer_reviews.sql`; рабочая база при реализации не менялась.
